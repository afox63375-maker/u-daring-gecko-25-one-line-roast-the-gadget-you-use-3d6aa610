# One-Line Roast: The Gadget You Use Every Day

The roast: **"My charger only works if I hold the cable at a 37-degree angle. It's not a charger, it's a trust exercise."**

Everyone has lived this: a frayed everyday charger that only delivers power at one exact, impossible angle, turning the simple act of charging into a ritual of holding still. The punchline reframes the gadget as a trust exercise — a fresh angle that avoids the prompt's own examples (dying phone, rating pop-up, smart kettle) and lands in two short sentences, 106 characters, ASCII-only for a low byte count.

## Run it

```sh
python3 main.py
```

This writes exactly the roast line — and nothing else — to `/output/entry.txt` (creating `/output` if needed), using only the Python standard library.
